# Security

## Supported Versions

Security fixes are provided for the current default branch. There is no supported tagged release line yet.

## Reporting a Vulnerability

Use the **Report a vulnerability** control on the repository [Security page](https://github.com/JDRV-space/shieldyoursite/security). Include the affected commit or version, impact, reproduction steps, and any known mitigations.

Do not open a public issue containing vulnerability details, secrets, credentials, private targets, or customer data. If private reporting is unavailable, open a non-sensitive issue asking the maintainers for an alternate private contact.

Maintainers will coordinate through the private advisory. No response-time guarantee is currently offered.
